# Core Rules Changes

## Reactions

- The reactive player has **1** reaction point per turn, regardless of any rules that would grant more.
- A rule that grants a free reaction may only be used once per turn.
- A movement reaction may not be used to embark in a Transport.

## Scoring

### Line

Bonus victory points from the Line rule are capped at 3 per turn, per army.

### Vanguard

- The Vanguard (X) Special Rule is used as written in the Age of Darkness FAQ & Errata (v1.3, Special Rules Updates).
- Models with the Vanguard rule have a Tactical Strength of 0 when determining who controls an objective.

## Psychic

The _Force Barrier_ psychic reaction (Telekinesis) grants a 4+ Invulnerable save, instead of a 3+ Shrouded save.

## Terrain

Scatter, crates, barrels, statues
: 6+ cover save for models behind and within 1". Difficult if crossing.

Defensive lines
: 5+ cover save for models behind and within 1". Difficult if crossing.

Craters, rivers, pools
: 6+ cover save, area terrain, difficult

Forests
: 6+ cover save, area terrain, difficult, obscuring

Ruins
: 5+ cover save, area terrain, difficult, obscuring

The '3"' rule for Medium terrain is not used.
