# Missions

All missions use Reserves, Seize the Initiative.

## 1. Point Assault

- 2VP for home objective
- 3VP per neutral objective
  - +2VP if 2 or more controlled
    - Not for first player in first turn
    - Not if all units controlling those objectives have Vanguard
- 4VP for enemy objective
  - +3VP if no enemy units within range

## 2. Forward Push

- 2VP per home objective
- 4VP per neutral objective
- 7VP per enemy objective

## 3. Retrieval

- 5 VP per objective

### Moving Intel

At the end of each battle round for each objective you control you may move the objective marker 3” in any direction. The objective marker cannot move through enemy models, cannot end overlapping any terrain or be moved off the battlefield. If both players are eligible to move an objective, the player who went second moves their ones first.

## 4. Confrontation

- 2VP per home objective
- 4VP per enemy objective

## 5. Conquest

- 3VP per objective
  - +4VP if 3 or more controlled, or +8VP if enemy objective is one of them
    - Not if all units controlling those objectives have Vanguard
