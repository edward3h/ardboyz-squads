# Missions

Board size _TBD_.

All missions use Reserves, Seize the Initiative.

::: {.mission}
## 1. Point Assault

![Point Assault map](static/maps/point-assault.svg)

- 2VP for home objective
- 3VP per neutral objective
  - +2VP if 2 or more controlled
    - Not for first player in first turn
    - Not if all units controlling those objectives have Vanguard
- 4VP for enemy objective
  - +3VP if no enemy units within range
:::

::: {.mission}
## 2. Forward Push

![Forward Push map](static/maps/forward-push.svg)

- 2VP per home objective
- 4VP per neutral objective
- 7VP per enemy objective
:::

::: {.mission}
## 3. Retrieval

![Retrieval map](static/maps/retrieval.svg)

- 5 VP per objective

> ### Moving Intel
>
> At the end of each battle round, for each objective you control, you may move the objective marker 3” in any direction. The objective marker cannot move through enemy models, end overlapping any terrain or be moved off the battlefield. If both players are eligible to move an objective, the player who went second moves their ones first.
:::

::: {.mission}
## 4. Confrontation

![Confrontation map](static/maps/confrontation.svg)

- 2VP per home objective
- 4VP per enemy objective
:::

::: {.mission}
## 5. Conquest

![Conquest map](static/maps/conquest.svg)

- 3VP per objective
  - +4VP if 3 or more controlled, or +8VP if enemy objective is one of them
    - Not if all units controlling those objectives have Vanguard
:::
